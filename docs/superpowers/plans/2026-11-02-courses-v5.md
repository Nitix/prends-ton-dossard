# « Prends ton dossard » v5 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A demo instance friends can enter without an account, the GPX map and the D+ profile linked, race-type-aware format fields, and an event end date derived from its formats.

**Architecture:** One server route pair behind an env var (demo), one migration (9i, `race_types.measures`), front changes in the login page, the route section, the format fieldset, the event form and the admin types page.

**Tech Stack:** Go + PocketBase v0.41.1, React 19, TanStack Router/Query, Tailwind 4 (theme « Crête », light and dark), Leaflet 1.9.4, Vitest.

**Spec:** `docs/superpowers/specs/2026-11-02-courses-v5-design.md`.

## Global Constraints

- Every v4 constraint holds (`.superpowers/sdd/2026-11-01-courses-v4/constraints.md`): error codes in 4 places, fr/en texts, 44 px, `aria-disabled` + ref guard, focus never on `<body>`, both themes (light and dark) and forced colours, signed commits staged one by one, never stage `docs/superpowers/specs/2026-10-31-courses-design.md`.
- No new dependency.
- Next migration: `9i_race_type_measures.go`.
- Never touch `.superpowers/worktrees/*` or `design/v4-*` branches.

## Review Focus

1. **Demo route on the real site**: without `DEMO_LOGIN_EMAIL`, `/api/app/demo` must not exist (404 for GET and POST). Test: `TestDemo_DisabledWithoutEnv` (Task 1).
2. **A hidden field that holds a value**: switching race type must never hide a filled measure. Test: `FormatFieldset — une mesure remplie reste visible quand le type ne l'utilise pas` (Task 2).
3. **End date and existing events**: editing an old multi-day event whose formats have no dates turns it into a one-day event; the form must say so before saving. Test: `EventForm — la période affichée suit les dates des épreuves` (Task 3).
4. **Map marker on a long track**: the marker must sit on the track at the cursor's km, also for 100k-point tracks, without lag. Test: `RouteSection — le repère de la carte suit le curseur du profil` (Task 4).
5. **Touch**: on a phone, touching the map track moves the profile cursor and does not pan the map away. Test in Task 4.
