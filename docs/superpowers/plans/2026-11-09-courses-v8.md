# Prends ton dossard v8 — an invitation worth opening — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The invitation page shows who invites, the invitee's next races with the friends going and the group's next races; the admin shares a ready message or the bare link; an invitation lasts 30 days.

**Architecture:** The public `lookup` route computes a preview at each call from the database (no storage). The create route returns a ready `message` written by `server/wording` from the same preview. The web page and the admin share dialog render what the routes return; the MCP tool passes `message` through.

**Tech Stack:** Go 1.27 + PocketBase v0.41 (`server/`), React 19 + TanStack Query + Vitest 5 browser mode (`web/`).

**Spec:** `docs/superpowers/specs/2026-11-09-courses-v8-design.md` (read it whole before any task; § numbers below refer to it).

## Review Focus

1. **A dead link leaks data** — an unknown, expired or used token must answer `404 invitation_invalid` with no preview (Task 2: `TestLookup_DeadLinksShowNothing`).
2. **The preview leaks a field** — notes, registration URL, prices, comments, carpool, emails, record ids, statuses must never appear; the keys are exactly those of § 4.1 (Task 2: `TestLookup_ShowsNothingElse`).
3. **A reset gets a preview** — a reset answers exactly `{runnerName, kind}` (Task 2: `TestLookup_ResetUnchanged`).
4. **The Paris midnight** — at 23:30 Paris (22:30 UTC) a race of the day is still upcoming, at 00:30 the next day it is gone (Task 2: `TestPreview_ParisMidnight`).
5. **Month-only and multi-day races** — a month-only race stays until the end of its month with day = 1st; an ongoing multi-day race keeps its first (past) day; the page shows no countdown for a past day (Task 2: `TestPreview_Days`; Task 5: `no countdown for a past day`).
6. **The invitee among the people, or `dns` shown** (Task 2: `TestPreview_People`).
7. **The group block** shows an event of the invitee (even `dns`) or a supporters-only event (Task 2: `TestPreview_Group`).
8. **The message** is gendered, carries the expiry, misses the U+00A0, or exists for a reset (Task 3: `TestInvitationMessage`; Task 4: `TestCreate_Message`).
9. **30 days applied to a reset** (Task 4: `TestCreate_Validity`).
10. **`lang` abuse** — anything but `en` gives French; no other body field read (Task 2 and Task 4 tests with `lang: "de"`).
11. **The shared day rules move changes the MCP home** — every existing `server/mcp` test passes unchanged (Task 1).
12. **The share dialog sends the wrong thing** — « Le message » must share `{title, text}`, « Le lien seul » `{url, title}`; copy follows the choice (Task 6).
13. **The page breaks on empty data** — `invitedBy: null`, empty `upcoming`, empty `group` (Task 5).
14. **The rate limit on `/api/app/invitations/`** stays (existing `TestInvitations_TokenRoutesAreRateLimited` passes).

  type Upcoming struct { Total int `json:"total"`; Races []UpcomingLine `json:"races"` }

      Upcoming  Upcoming    `json:"upcoming"`
      Group     []GroupLine `json:"group"`
  }
  // ComputePreview is the preview of runnerID on the Paris day today; createdBy is
  // invitations.created_by (empty: no author). w names the generated formats.
  func ComputePreview(app core.App, runnerID, createdBy, today string, w wording.Words) (Preview, error)

  func ParisDay(t time.Time) string
