# « Prends ton dossard » v3.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Apply the user's feedback on v3: no « Terminé »/« Abandon » before the race, a topographic map under the GPX track, a calendar link that can be shown again, and the installed app named « Prends ton dossard ».

**Architecture:** Small changes to existing flows. One server validation and one migration (9h), a lazily loaded Leaflet map in the route section, and copy changes.

**Tech Stack:** Go + PocketBase v0.41.1, React 19 + Vite 8 + TanStack Query, Tailwind 4, Temporal, Leaflet 1.9.4 (new).

**Spec:** `docs/superpowers/specs/2026-11-01-courses-v3.1-design.md` (complements `2026-11-01-courses-v3-design.md`).

## Global Constraints

- Every v3 constraint holds (`.superpowers/sdd/2026-11-01-courses-v3/constraints.md`): tools and `env.sh`, error codes in `codes.go` + `ERROR_CODES` + fr/en + `apperr_test.go`, fr/en texts in the same task, `aria-disabled` + ref guard, focus never on `<body>`, 44 px targets, per-migration rules, signed commits staged one by one, never stage `docs/superpowers/specs/2026-10-31-courses-design.md`.
- **One exception:** the user chose Leaflet. Add `leaflet@1.9.4` (dependency) and `@types/leaflet` (dev dependency), exact versions, nothing else.
- Migration naming: the next one is `9h_calendar_token.go`.
- Tests never load a real map tile from the network.

## Review Focus

1. **A race moved later after its result was typed**: editing that participation (note, time) must still work. Test: `TestParticipations_StatusBeforeRace` row « an existing finished status is kept when the race moves later » (Task 1).
2. **The race day itself**: « Terminé » is offered and accepted on the day (Paris). Tests: the « same day » rows (Task 1, server and front).
3. **The map on a phone**: the page must still scroll (no wheel zoom; the map does not grab the whole screen), and the zoom buttons are 44 px. Test: `TrackMap — zoom buttons are 44 px, wheel zoom is off` (Task 2).
4. **A calendar link from v3** (hash only): the Profile must not offer « Afficher le lien » for it, nor crash. Tests: `TestCalendarRoutes` legacy row, `CalendarSection — un lien ancien invite à en créer un nouveau` (Task 3).
5. **Tiles that fail** (offline, blocked): the track and the numbers stay. Test: `TrackMap — the track is drawn without tiles` (Task 2).
